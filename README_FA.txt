# برنامه مدیریت انبار (نسخه اولیه)

## محتویات
- `index.html`: برنامه اصلی
- `manifest.json`: تنظیمات نصب به‌صورت PWA
- `sw.js`: کش برنامه برای بازشدن آفلاین پس از بارگذاری اولیه
- `icon.svg`: آیکن برنامه

## انتشار رایگان با GitHub Pages
1. وارد GitHub شوید و یک مخزن جدید (Repository) بسازید؛ نامی مثل `warehouse-app` انتخاب کنید.
2. اگر گزینه Public/Private را می‌بینید، برای استفاده ساده از GitHub Pages در پلن رایگان، مخزن Public بسازید.
3. از دکمه **Add file → Upload files** چهار فایل را از این ZIP استخراج و بارگذاری کنید؛ فایل‌ها باید در ریشه مخزن باشند، نه داخل پوشه اضافی.
4. پایین صفحه Commit changes را بزنید.
5. بروید به **Settings → Pages**.
6. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید؛ Branch را `main` و Folder را `/(root)` بگذارید و Save کنید.
7. پس از چند دقیقه، آدرس سایت در همان صفحه ظاهر می‌شود.
8. آدرس را با Chrome اندروید باز کنید و از منوی سه‌نقطه گزینه **Add to Home screen** یا **Install app** را بزنید.

## نکات مهم
- برای آفلاین شدن، سایت را یک بار در حالت آنلاین باز کنید تا فایل‌ها کش شوند.
- داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند؛ از بخش تنظیمات نسخه پشتیبان JSON بگیرید.
- این نسخه اولیه است؛ داده‌ها بین دستگاه‌ها همگام نمی‌شوند و رمز ورود/چندکاربره ندارد.
- فاکتور خرید و فروش، پیش‌نویس، ثبت نهایی، محاسبه جمع/تخفیف/مانده و تغییر موجودی پایه دارد. قبل از استفاده تجاری واقعی، آن را با داده‌های آزمایشی بررسی کنید.
- در این نسخه CSV خروجی می‌گیرد؛ فایل CSV را می‌توان در Excel باز کرد. خروجی PDF/Excel واقعی، واردکردن فایل‌ها، برگشت کالا، چندانباره و حسابداری پیشرفته در نسخه بعدی قابل افزودن است.
